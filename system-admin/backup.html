Back up the database manually

Until backups are built into Siknayan, make a copy of the database with phpMyAdmin (included with XAMPP):

  1. Open http://localhost/phpmyadmin on the server computer.
  2. Select the siknayan database, then open the Export tab.
  3. Keep Quick and SQL selected, and choose Export.
  4. Store the downloaded .sql file somewhere private. It contains every account, including password hashes.

Uploaded files (module materials, submissions and profile photos) are stored separately in backend/storage/app. Copy that folder too.
