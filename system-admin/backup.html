Back up the database manually

Until backups are built into Siknayan, make a copy of the database with phpMyAdmin (included with XAMPP). Do this on the server computer, where Siknayan is installed.

1 Before you start

Open the XAMPP Control Panel and make sure Apache and MySQL are both running. phpMyAdmin will not open without Apache.

2 Back up the database

  1. Open http://localhost/phpmyadmin.
  2. Select the siknayan database, then open the Export tab.
  3. Keep Quick and SQL selected, and choose Export.
  4. Rename the downloaded file with the date, for example siknayan-2026-10-23.sql, so older copies are not overwritten.

Store the .sql file somewhere private. It contains every account, including password hashes.

3 Back up the uploaded files

Module materials, submissions and profile photos are stored separately from the database. Copy this whole folder next to your .sql file:

Siknayan LMS\final\backend\storage\app

4 Restore from a backup

  1. In phpMyAdmin, create an empty database named siknayan (or select the existing one).
  2. Open the Import tab, choose your .sql file, and choose Import.
  3. Copy the saved app folder back into backend\storage\.

Importing into a database that already has data replaces it. Make a fresh backup first if you are not sure.

5 Optional: the settings file

Keep a private copy of backend\.env. It holds the database and email settings needed to run Siknayan again on a new computer.

The settings file contains passwords. Never share it, email it, or upload it online.
